# K-MODU 관리자 크리에이터 캠페인 운영 설계

## 목표

운영자가 코드나 데이터베이스를 직접 수정하지 않고 크리에이터 캠페인을 등록하고, 신청자와 초대자를 관리하며, 콘텐츠 제출부터 정산까지 진행 상태를 운영할 수 있게 한다. 기존 디자이너 스튜디오는 수정하지 않는다. 메인 페이지의 우측 고정 퀵 링크에는 크리에이터 센터 진입 버튼을 추가한다.

## 범위

### 포함

- 관리자 캠페인 목록, 등록, 수정, 마감
- 카테고리, 국가, 플랫폼, 보상, 모집 인원, 일정, 이미지, 미션 설정
- 캠페인 신청자 승인·거절
- 승인된 크리에이터 직접 초대
- 참여 상태를 배송, 제작, 검수, 게시, 정산, 완료로 변경
- 참여 상태 변경 이력 저장
- 메인 우측 고정 배너에 `크리에이터 센터` 링크 추가
- 관리자와 크리에이터 화면의 PC·모바일 검증

### 제외

- 디자이너 스튜디오 화면과 기존 디자이너 API 변경
- 자동 이메일·카카오 알림
- 자동 정산 송금
- 크리에이터가 캠페인을 직접 생성하는 기능
- 데이터가 있는 캠페인의 물리적 삭제

## 화면 구조

### 관리자 캠페인 목록 `/dashboard/admin/campaigns`

- 상단에 전체, 모집 중, 진행 중, 마감 상태 필터를 둔다.
- 각 행은 캠페인명, 패션·뷰티 카테고리, 대상 국가, 플랫폼, 신청 수, 승인 수, 모집 정원, 신청 마감일, 상태를 표시한다.
- 주요 작업은 `새 캠페인`, `상세 운영`, `수정`, `마감`이다.
- 데이터가 없는 경우 새 캠페인 등록으로 연결되는 빈 상태를 보여준다.

### 등록·수정 `/dashboard/admin/campaigns/new`, `/dashboard/admin/campaigns/[id]/edit`

- 필수 입력: 캠페인명, 카테고리, 국가, 플랫폼, 미션 설명, 보상, 모집 인원, 신청 마감일, 콘텐츠 마감일
- 선택 입력: 제품·캠페인 이미지 URL
- 저장 전 서버에서 날짜 순서, 모집 인원, 필수 배열, URL 형식을 검증한다.
- 생성 시 기본 상태는 `draft`이며 운영자가 `모집 시작`을 눌러 `recruiting`으로 전환한다.

### 상세 운영 `/dashboard/admin/campaigns/[id]`

- 캠페인 요약과 모집 현황을 상단에 표시한다.
- 신청자와 초대자를 한 목록에서 출처와 현재 상태로 구분한다.
- 신청자는 승인 시 `matched`, 거절 시 `cancelled`로 전환한다.
- 승인된 크리에이터를 검색해 직접 초대할 수 있다.
- 운영자는 허용된 다음 단계로만 참여 상태를 변경한다.
- 콘텐츠 제출 이력, 검수 메모, 성과, 정산 상태를 함께 확인한다.

## 메인 우측 고정 배너

- 기존 `디자이너 스튜디오`, `카카오 문의`와 동일한 크기·형태를 재사용한다.
- `크리에이터 센터` 버튼은 두 버튼 사이에 배치하고 `/dashboard/creator`로 연결한다.
- 데스크톱에서는 우측 세로 스택, 모바일에서는 화면을 가리지 않도록 크기와 간격을 축소한다.
- 로그인하지 않은 사용자는 기존 인증 정책에 따라 로그인 페이지로 이동한다.
- 번역이 활성화된 페이지에서는 기존 다국어 체계에 맞춰 버튼 문구를 번역한다.

## 데이터와 상태

- 기존 `campaigns`, `campaign_participations`, `content_submissions`, `campaign_events`, `campaign_performance`, `creator_accounts`를 재사용한다.
- `campaigns.status`에는 `draft`를 추가해 미완성 캠페인이 공개되지 않게 한다.
- 캠페인 삭제 API는 만들지 않는다. 모집 전 초안은 보관하고, 공개 이후에는 `closed`로 마감한다.
- 모든 참여 상태 변경은 참여 레코드 갱신과 `campaign_events` 기록을 하나의 트랜잭션으로 처리한다.
- 모집 정원과 중복 참여 검사는 잠금이 포함된 서버 트랜잭션에서 수행한다.

## 권한과 오류 처리

- 모든 관리자 캠페인 API는 기존 관리자 인증 가드를 사용한다.
- 크리에이터 계정은 관리자 API에 접근할 수 없다.
- 존재하지 않는 캠페인·크리에이터는 404, 상태 충돌·정원 초과·중복 참여는 409, 입력 오류는 400으로 응답한다.
- 화면에는 서버 메시지를 그대로 노출하지 않고 사용자가 취할 수 있는 다음 행동을 한국어로 안내한다.

## 구성 요소

- `AdminCampaignList`: 필터와 운영 현황 목록
- `AdminCampaignForm`: 등록·수정 공용 폼
- `AdminCampaignOperations`: 신청 승인, 초대, 단계 변경
- `AdminCampaignStatusAction`: 모집 시작과 마감
- 캠페인 관리자 API: 생성, 수정, 상태 변경, 참여 승인·거절·단계 변경
- 기존 초대 API와 크리에이터 캠페인 도메인 함수 재사용
- 메인 퀵 링크 마크업·스타일·다국어 사전에 크리에이터 센터 항목 추가

## 테스트와 검증

- 권한, 입력값, 날짜 순서, 정원, 중복 참여, 상태 전이, 이벤트 기록 자동 테스트
- 기존 크리에이터 센터와 디자이너 스튜디오 회귀 테스트
- 전체 테스트와 프로덕션 빌드
- 관리자 목록·등록·상세 화면을 1440×900과 390×844에서 확인
- 메인 우측 배너를 PC·모바일 및 한국어·베트남어·중문·영문에서 확인
- 운영 배포 후 관리자 경로, 크리에이터 경로, 메인 페이지의 콘솔 오류와 가로 넘침 확인

## 완료 기준

- 운영자가 관리자 화면만으로 캠페인을 모집 시작부터 완료까지 운영할 수 있다.
- 승인된 크리에이터가 기존 크리에이터 센터에서 초대·신청·제출·성과 흐름을 계속 사용할 수 있다.
- 메인 페이지에서 크리에이터 센터 진입점이 명확히 보인다.
- 디자이너 스튜디오 코드와 동작은 변경되지 않는다.
