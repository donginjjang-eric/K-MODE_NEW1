# 크리에이터 센터 뷰티 거래 체험 데이터 설계

## 목적

관리자 계정 `donginjjang@gmail.com`의 전용 크리에이터 프로필에서 추천, 초대, 진행, 제출, 성과, 정산 메뉴를 실제 데이터처럼 확인한다. 운영 캠페인과 혼동되지 않도록 모든 체험 데이터에는 `[DEMO]` 표시와 고정 식별자를 사용한다.

서비스 관점은 한국 공급사가 말레이시아·베트남 등 해외 크리에이터에게 제품을 보내 콘텐츠와 현지 판매를 만드는 구조다. 크리에이터 센터는 해외 사용자의 활동·수익 관점으로 표현한다.

## 체험 시나리오

동일한 K-뷰티 공급사와 크리에이터가 협업 단계별로 진행하는 모습을 네 개의 캠페인 스냅샷으로 보여준다.

1. `[DEMO] 비타 글로우 세럼 글로벌 시딩`
   - 상태: 모집 중
   - 노출: 추천 캠페인, 마감 임박
   - 의미: 크리에이터가 새 제안을 발견하는 단계
   - 공급·시장: 한국 공급사 → 말레이시아 크리에이터, 보상 MYR
2. `[DEMO] 세라마이드 크림 말레이시아 론칭`
   - 상태: 초대됨
   - 노출: 홈 초대 수, 내 미션
   - 의미: 공급사 제안을 수락하거나 거절하는 단계
   - 공급·시장: 한국 공급사 → 말레이시아 크리에이터, 보상 MYR
3. `[DEMO] 선 쿠션 숏폼 리뷰`
   - 상태: 검수 중
   - 노출: 진행 중 캠페인, 내 미션 상세, 제출 관리
   - 포함 데이터: 배송 메모, 1차 제출물, 수정 요청, 상태 이벤트
   - 의미: 제품 배송부터 콘텐츠 검수까지의 소통 단계
   - 공급·시장: 한국 공급사 → 베트남 크리에이터, 보상 VND
4. `[DEMO] 립 틴트 공동판매`
   - 상태: 완료
   - 노출: 내 미션, 제출 관리, 정산
   - 포함 데이터: 게시 URL, 조회·좋아요·댓글·주문·매출, 지급 완료 정산
   - 의미: 게시 이후 판매성과와 정산까지의 거래 단계
   - 공급·시장: 한국 공급사 → 말레이시아 크리에이터, 매출·정산 MYR

## 구현 방식

- 관리자 전용 `데모 데이터 채우기` 기능을 추가한다.
- 현재 로그인한 사용자가 관리자일 때만 실행할 수 있다.
- `campaigns`, `campaign_participations`, `content_submissions`, `campaign_events`, `campaign_performance`의 기존 구조를 그대로 사용한다.
- 고정 ID와 upsert를 사용해 여러 번 실행해도 중복 생성되지 않게 한다.
- 관리자 전용 `데모 데이터 초기화` 기능도 제공하며 `[DEMO]` 고정 ID만 제거한다.
- 실제 공개 크리에이터나 기존 캠페인 데이터는 수정하지 않는다.

## 화면 연결

- 홈은 `크리에이터 활동·수익센터`로 구성하고 추천 캠페인, 오늘 마감, 예상 수익, 이번 달 주문 KPI를 즉시 확인한다.
- 홈의 `내 미션 보드`는 제품 수령 → 콘텐츠 제작 → 검수 → 게시 → 정산 단계를 한 줄로 보여준다.
- 추천 캠페인: 모집 중인 세럼 캠페인을 확인하고 지원 흐름을 시험한다.
- 내 미션: 초대·검수·완료 단계가 함께 표시된다.
- 콘텐츠 제작: 수정 요청이 있는 선 쿠션 제출물과 게시 완료 립 틴트 제출물을 확인한다.
- 성과: 캠페인별 조회·좋아요·댓글·주문·매출을 확인한다.
- 수익·정산: KRW 기준 예상·지급 금액과 완료 상태를 확인한다.
- 등급: 활동 수, 게시 완료 수, 주문 성과로 산정한 운영자 체험 등급과 다음 등급 조건을 확인한다.
- 내 정보: `K-MODU 운영자` 프로필은 유지한다.
- 언어: 크리에이터 센터 핵심 메뉴와 홈 KPI는 한국어·말레이어·베트남어·영어로 전환되며 말레이어를 한국어 다음 순서로 제공한다.

## 안전장치

- 관리자 권한을 서버에서 다시 확인한다.
- 데모 ID에는 `demo-beauty-` 접두사를 사용한다.
- 초기화는 해당 접두사 데이터만 대상으로 한다.
- 공급사명과 콘텐츠 URL은 명확한 가상 값으로 구성한다.
- 실행 결과에 생성·갱신 건수를 반환하고 실패 시 트랜잭션 전체를 롤백한다.

## 검증 기준

1. 데모 채우기를 두 번 실행해도 건수가 늘지 않는다.
2. 실제 기존 캠페인과 크리에이터 데이터가 바뀌지 않는다.
3. 관리자 크리에이터 센터의 모든 메뉴에 관련 데이터가 표시된다.
4. PC와 모바일에서 카드와 상태 라벨이 정상 표시된다.
5. 데모 초기화 후 기존 운영 데이터만 남는다.
