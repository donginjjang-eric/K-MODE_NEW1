# 크리에이터 센터 잔여 화면 완성 설계

## 목표

이미 개편된 내 미션 상세와 수익·정산 화면에 맞춰 콘텐츠 제작, 성과, 등급, 프로필을 실제 데이터 중심의 완성된 화면으로 개편하고 홈과 추천 캠페인의 시각적 일관성을 정리한다.

## 범위

### 콘텐츠 제작

- 캠페인별 제작 카드를 사용한다.
- 캠페인명, 카테고리, 현재 상태, 다음 행동, 제출 횟수, 최근 검수 의견을 분리해 표시한다.
- `creating`과 `review` 상태에서만 기존 제출 폼을 노출한다.
- 그 외 상태는 미션 상세로 이동하는 버튼과 현재 단계 안내를 제공한다.
- 캠페인이 없으면 내 미션 화면으로 이어지는 빈 상태를 제공한다.

### 성과

- 조회, 좋아요, 댓글, 주문의 전체 합계를 요약 카드로 표시한다.
- 캠페인별로 조회, 참여 반응, 주문, 매출을 카드 또는 읽기 쉬운 행으로 표시한다.
- 참여율은 `(좋아요 + 댓글) / 조회 × 100`, 주문 전환율은 `주문 / 조회 × 100`으로 계산하며 조회가 0이면 0으로 처리한다.
- 매출은 통화별로만 표시하고 서로 다른 통화를 합산하지 않는다.
- 각 성과 항목에서 해당 미션 상세로 이동할 수 있어야 한다.

### 등급

- 현재 등급과 완료 캠페인 수를 주요 정보로 표시한다.
- 다음 등급까지 남은 완료 캠페인 수와 진행률을 표시한다.
- STARTER, RISING, PRO의 조건과 제공 혜택을 카드로 설명한다.
- PRO 사용자는 최고 등급 유지 안내를 표시한다.
- 실제 데이터에 없는 점수나 순위는 만들지 않는다.

### 프로필

- 프로필 기본 정보, 활동 정보, 관심 분야, 계정 상태를 카드로 분리한다.
- 표시 이름, 플랫폼, 활동 국가, 카테고리, Google 이메일, 승인 상태만 실제 데이터로 표시한다.
- 현재 수정 API가 없으므로 입력 폼이나 작동하지 않는 수정 버튼을 만들지 않는다.
- 정보 변경은 운영팀 확인 방식임을 명확히 안내한다.

### 홈과 추천 캠페인

- 기존 기능과 데이터 조회는 변경하지 않는다.
- 잔여 화면과 제목, 카드 여백, 빈 상태, 주요 버튼의 시각적 일관성만 점검하고 필요한 범위에서 조정한다.

## 표시 로직과 데이터 경계

- 화면 표시용 계산은 `creator-center` 또는 별도 표현 도우미의 순수 함수로 둔다.
- 콘텐츠 제출 API와 데이터 저장 방식은 변경하지 않는다.
- 기존 크리에이터 소유권 범위 조회를 유지한다.
- 관리자 미리보기의 페르소나 및 통화 필터를 유지한다.
- 데이터가 없는 필드는 추정하거나 고정 문구로 값처럼 표시하지 않는다.

## 상태와 오류 처리

- 성과 행이 없으면 게시 후 성과가 표시된다는 빈 상태를 제공한다.
- 제출할 수 없는 상태에서는 제출 폼 대신 현재 단계와 미션 상세 링크를 표시한다.
- 프로필 정보가 비어 있으면 `등록되지 않음`으로 표시한다.
- 계산 분모가 0인 경우 참여율과 전환율은 `0%`로 표시한다.

## 반응형 디자인

- 데스크톱은 요약 카드와 상세 콘텐츠의 2단 또는 다단 구성을 사용한다.
- 760px 이하에서는 모든 주요 카드와 행을 한 열로 배치한다.
- 표보다 카드와 유연한 그리드를 우선해 모바일 가로 스크롤을 최소화한다.

## 검증과 배포

- 성과율과 등급 진행 계산을 단위 테스트한다.
- 각 화면이 필요한 섹션과 링크를 포함하는지 계약 테스트한다.
- 기존 콘텐츠 제출, 크리에이터 소유권, 통화 분리 테스트를 유지한다.
- Next.js 운영 빌드를 통과한 뒤 Railway의 `k-modu` production 서비스에 배포한다.
- 운영 주소에서 콘텐츠 제작, 성과, 등급, 프로필을 데스크톱 크기로 확인한다.
- 브라우저가 뷰포트 변경을 지원하면 모바일 크기도 확인하고, 지원하지 않으면 반응형 CSS와 빌드 검증 범위를 명시한다.
