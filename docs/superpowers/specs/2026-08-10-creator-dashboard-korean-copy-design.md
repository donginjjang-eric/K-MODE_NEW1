# 크리에이터 대시보드 한국어 문구 통일 설계

## 목표

크리에이터 대시보드에서 사용자에게 노출되는 영어 문구를 쉽고 자연스러운 한국어로 통일한다. 사용자가 캠페인 탐색, 지원, 미션 수행, 콘텐츠 제출, 성과 입력, 정산 확인을 별도 설명 없이 이해할 수 있어야 한다.

## 범위

- 크리에이터 홈, 추천 캠페인, 내 미션, 미션 상세, 콘텐츠 제작, 성과, 수익·정산, 등급, 프로필
- 공통 내비게이션과 크리에이터 계정 영역
- 필터 이름과 선택지, 버튼, 빈 화면, 카드 보조 문구
- 지원·초대·제출·성과 입력의 성공, 실패, 진행 중 메시지
- 캠페인 및 참여 상태값, 진행 단계, 검수 상태 등 데이터 기반 영문 표시

관리자 전용 화면과 데이터베이스에 저장된 원문 콘텐츠는 이번 범위에서 제외한다.

## 표현 원칙

- 직역보다 사용자가 다음 행동을 바로 이해할 수 있는 표현을 사용한다.
- `K-MODU`, 이메일, URL, 통화 코드(KRW, USD, VND, TWD, MYR), 플랫폼 고유명사는 유지한다.
- 내부 API 값과 데이터베이스 상태값은 변경하지 않고 표시 단계에서만 한국어로 변환한다.
- 반복 상태값은 공통 번역 함수로 관리해 화면별 표현 차이와 누락을 방지한다.
- 장식용 영문 소제목도 한국어로 바꾸되 브랜드 로고의 영문 표기는 유지한다.

## 주요 표현 예시

- `RECOMMENDED CAMPAIGNS` → `추천 캠페인`
- `Category` → `카테고리`
- `Market` → `활동 국가`
- `Platform` → `활동 채널`
- `Apply filters` → `조건 적용`
- `Clear` → `초기화`
- `Apply now` → `지금 지원하기`
- `My missions` → `내 미션`
- `Mission timeline` → `진행 단계`
- `Submit for review` → `검수 요청하기`
- `Performance saved.` → `성과가 저장되었습니다.`

## 구현 구조

1. 크리에이터 전용 표시 문구 모듈에 상태, 단계, 매칭 이유를 한국어로 바꾸는 함수를 둔다.
2. 각 페이지와 상호작용 컴포넌트의 고정 영어 문구를 한국어로 교체한다.
3. 서버가 반환한 오류 문구를 그대로 노출하지 않고, 크리에이터 화면에서는 상황별 한국어 안내를 우선 표시한다.
4. 숫자와 날짜는 한국 사용자에게 익숙한 형식으로 표시하되 통화 단위는 원래 코드를 보존한다.

## 검증

- 크리에이터 대시보드 소스에서 허용되지 않은 사용자 노출 영어 문구를 검사하는 계약 테스트를 추가한다.
- 상태 번역 함수의 주요 상태값을 단위 테스트한다.
- 관련 테스트와 프로덕션 빌드를 실행한다.
- 로그인 가능한 로컬 환경에서 추천 캠페인과 주요 하위 화면을 데스크톱 크기로 확인한다.
- 반응형 레이아웃에 영향을 주는 문구 길이를 모바일 크기로 확인한다.

## 완료 기준

- 브랜드명, 고유명사, URL, 이메일, 통화 코드를 제외하고 크리에이터 대시보드의 사용자용 영어가 보이지 않는다.
- 내부 상태 코드는 유지되며 화면에서만 일관된 한국어로 표시된다.
- 성공, 오류, 빈 화면 안내가 사용자의 다음 행동을 명확히 설명한다.
- 자동 테스트와 화면 검증을 통과한다.
