# 크리에이터 내 미션 카드 화면 설계

## 목표

`내 미션` 화면을 단순 목록에서 행동 중심의 카드 화면으로 바꾼다. 크리에이터가 각 캠페인의 현재 단계와 다음 행동을 즉시 이해하고, 상세 화면으로 자연스럽게 이동할 수 있어야 한다.

## 정보 구조

### 상단 요약

- 진행 중인 미션 수
- 검수 대기 미션 수
- 완료한 미션 수
- 숫자와 짧은 설명을 가진 3개의 요약 카드로 표시한다.

### 진행 중인 미션

진행 중인 캠페인은 큰 카드로 표시한다. 각 카드에는 다음 정보가 포함된다.

- 카테고리에 맞는 대표 이미지
- 캠페인명과 현재 상태 배지
- `지원 → 매칭 → 배송 → 제작 → 검수 → 게시 → 정산 → 완료` 진행 단계
- 현재 해야 할 일을 설명하는 한국어 안내
- 콘텐츠 마감일
- 예상 보상
- `미션 자세히 보기` 버튼
- 초대 상태일 때 `초대 수락`, `초대 거절` 동작

### 완료한 미션

완료 상태의 캠페인은 진행 중 카드와 분리해 아래쪽에 간결한 카드로 표시한다. 완료 배지, 캠페인명, 보상, 상세 보기 링크만 제공한다.

### 빈 화면

진행 중인 미션이 없으면 이유를 설명하고 `추천 캠페인 보기` 버튼을 제공한다. 완료한 미션만 있는 경우 완료 영역은 그대로 유지한다.

## 상태 분류

- 진행 중: `applied`, `invited`, `matched`, `shipping`, `creating`, `review`, `published`, `settlement`
- 완료: `completed`
- 종료: `cancelled`
- 검수 대기 요약: `review`

내부 상태 코드는 변경하지 않고 기존 `creatorStatusLabel`과 `creatorNextActionLabel`을 사용해 화면에서만 한국어로 표시한다.

## 시각 디자인

- 기존 크리에이터 센터의 아이보리, 검정, 청록 색상 체계를 유지한다.
- 카드 본문은 흰색, 이미지 영역은 좌측 또는 상단, 핵심 행동 버튼은 청록색으로 표시한다.
- 진행 단계는 완료·현재·예정 상태가 명확히 구분되는 가로 스텝으로 만든다.
- 데스크톱에서는 이미지와 정보를 2열로, 모바일에서는 세로로 쌓는다.
- 카드 사이 여백과 구분선을 충분히 사용해 빈 공간이 아니라 의도된 정보 영역으로 보이게 한다.

## 데이터와 예외 처리

- 현재 미션 조회 데이터에 캠페인 이미지가 없으므로 카테고리에 따라 기존 캠페인 대표 이미지를 사용한다.
- 마감일이 없으면 `일정 확인 중`, 보상이 없으면 `협의 후 안내`로 표시한다.
- 알 수 없는 상태값은 공통 표시 함수의 기존 안전한 대체 동작을 유지한다.

## 검증

- 상태별 진행 단계 계산을 테스트한다.
- 진행 중/완료/검수 대기 분류를 테스트한다.
- 기존 초대 수락·거절과 상세 링크 계약을 유지한다.
- 프로덕션 빌드를 실행한다.
- 운영 배포 후 데스크톱과 모바일에서 카드, 단계 표시, 버튼, 아이콘과 콘솔 오류를 확인한다.

## 완료 기준

- 사용자가 캠페인명, 현재 단계, 다음 행동, 마감일, 보상을 한 카드에서 확인할 수 있다.
- 진행 중 미션과 완료한 미션이 명확히 분리된다.
- 데스크톱과 모바일에서 정보가 겹치거나 잘리지 않는다.
- 기존 지원·초대·상세 보기 기능이 유지된다.
