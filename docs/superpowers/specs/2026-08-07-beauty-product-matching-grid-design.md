# K-MODU 뷰티 상품 매칭 그리드 설계

## 목표

뷰티 상품 목록을 일반 쇼핑몰 진열이 아니라 글로벌 크리에이터 협업 기회를 탐색하는 매칭 보드로 보이게 한다. 데스크톱에서는 한 줄에 5개, 최초 10개를 노출하고 사용자가 `더보기`를 누를 때마다 다음 10개를 표시한다.

## 상품 구성

- 총 30개의 샘플 상품을 제공한다.
- 카테고리는 스킨케어, 메이크업, 헤어·바디로 균형 있게 구성한다.
- 판매 희망 국가는 베트남(VN), 대만(TW), 미국(US)을 조합한다.
- 각 상품은 영문 상품명, 핵심 판매 포인트, 권장 콘텐츠 형식, 모집 크리에이터 수를 가진다.
- 기존 6개 상품과 이미지 자산은 유지하고 신규 상품은 시각적으로 구분되는 제품 이미지를 사용한다.

## 카드 디자인

- 데스크톱 5열, 태블릿 3열, 모바일 2열로 구성한다.
- 이미지 위에는 `RECRUITING` 상태 배지와 저장 아이콘을 배치한다.
- 이미지 아래 정보 순서는 카테고리·판매 국가, 상품명, 핵심 키워드, 모집 규모, `매칭 상세보기` 순서로 한다.
- 모집 규모는 금색 포인트 컬러로 강조하고 나머지는 아이보리·블랙 기반의 기존 K-MODU 스타일을 유지한다.
- 호버 시 카드가 과도하게 움직이지 않고 이미지 확대, 경계선, CTA 반전만 적용한다.

## 목록 동작

- 최초 표시 개수는 10개다.
- `더보기` 클릭마다 현재 필터 결과에서 다음 10개를 추가한다.
- 남은 상품이 없으면 더보기 버튼을 숨긴다.
- 카테고리나 국가 필터가 바뀌면 표시 개수를 10개로 초기화한다.
- 필터 결과가 0개면 기존 빈 상태 문구를 표시한다.
- 숨김 처리는 DOM 삭제가 아니라 `hidden` 속성으로 처리해 기존 상세 모달 연결을 유지한다.

## 접근성

- 더보기 버튼은 남은 상품 수를 보조 문구로 알린다.
- 카드와 더보기 버튼은 키보드로 조작할 수 있다.
- 필터 후 표시된 결과 개수를 라이브 영역으로 안내한다.
- 장식 아이콘은 스크린리더에서 제외하고 상품 이미지 대체 텍스트는 유지한다.

## 검증 기준

- 1440px에서 정확히 5열이며 최초 10개만 표시된다.
- 더보기 클릭 후 20개, 다시 클릭 후 30개가 표시되고 버튼이 사라진다.
- 390px에서 2열이며 가로 스크롤이 생기지 않는다.
- 필터 변경 시 첫 10개 상태로 초기화된다.
- 모든 카드에서 기존 상품 상세 모달이 열린다.
- 빌드와 인라인 스크립트 검사에 오류가 없다.
