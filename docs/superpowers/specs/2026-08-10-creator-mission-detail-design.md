# 크리에이터 미션 상세 페이지 재설계

## 목표

미션 상세 페이지를 브라우저 기본 문서 형태에서 크리에이터 센터의 카드형 작업 화면으로 바꾼다. 캠페인의 현재 상태, 다음 행동, 일정, 보상, 콘텐츠 제출, 성과 입력과 활동 기록을 한눈에 이해할 수 있어야 한다.

## 화면 구조

### 상단 캠페인 요약

- `내 미션`으로 돌아가는 링크
- 카테고리별 대표 이미지
- 현재 상태 배지
- 캠페인명
- 다음 행동 안내
- 콘텐츠 마감일과 예상 보상

### 진행 단계

- `지원 → 초대 → 매칭 → 배송 → 제작 → 검수 → 게시 → 정산 → 완료`를 가로 단계로 표시한다.
- 완료 단계, 현재 단계, 예정 단계를 색상과 아이콘으로 구분한다.
- 취소 상태는 별도 종료 안내로 표시한다.

### 캠페인 안내

- 캠페인 설명
- 배송 안내
- 콘텐츠 마감일
- 예상 보상
- 정보를 카드와 설명 목록으로 정리한다.

### 콘텐츠 제출과 성과

- 제출 가능한 상태에서 콘텐츠 URL과 게시 문구 입력폼을 카드로 표시한다.
- 게시 이후 상태에서는 조회수, 좋아요, 댓글, 주문, 매출, 통화를 구분된 입력칸으로 표시한다.
- 주요 저장 버튼은 청록색으로 강조한다.
- 오류와 성공 메시지는 입력 영역 아래에 표시한다.

### 제출 내역과 활동 기록

- 제출 내역은 버전, 상태, 게시 문구, 검수 의견, 게시 링크를 개별 카드로 표시한다.
- 활동 기록은 날짜와 메시지를 시간순 목록으로 표시한다.
- 데이터가 없으면 짧은 빈 상태 안내를 표시한다.

## 문구 처리

- 공통 상태는 `creatorStatusLabel`을 사용한다.
- 다음 행동은 `creatorNextActionLabel`을 우선 사용해 저장된 영문 내부 문구 노출을 막는다.
- 캠페인 설명과 활동 기록처럼 데이터베이스에 저장된 콘텐츠는 원문을 보존한다.
- 체험 캠페인 설명은 화면 표시 단계에서 등록된 한국어 체험 설명으로 대체한다.

## 시각 디자인

- 기존 크리에이터 센터의 아이보리, 검정, 청록, 골드 색상 체계를 유지한다.
- 상단은 이미지와 정보의 2열 히어로 카드로 구성한다.
- 본문은 넓은 주 콘텐츠와 좁은 보조 정보 영역으로 구성하되, 모바일에서는 한 열로 쌓는다.
- 모든 폼 요소에 라벨, 충분한 높이, 테두리, 포커스 상태를 제공한다.
- 기본 `ol`, `ul`, `input`, `button` 모양이 직접 노출되지 않도록 전용 스타일을 적용한다.

## 검증

- 상태별 진행 단계 계산과 체험 설명 변환을 테스트한다.
- 성과 입력, 제출 폼, 초대 동작의 기존 노출 조건을 유지한다.
- 관련 계약 테스트와 프로덕션 빌드를 실행한다.
- 운영 배포 후 데스크톱과 모바일에서 레이아웃, 입력폼, 단계 표시, 가로 넘침과 콘솔 오류를 확인한다.

## 완료 기준

- 브라우저 기본 스타일로 보이는 요소가 없다.
- 사용자가 현재 상태와 다음 행동을 상단에서 즉시 이해할 수 있다.
- 성과 입력과 제출 내역이 명확히 구분된다.
- 데스크톱과 모바일에서 내용이 겹치거나 잘리지 않는다.
- 기존 미션 기능과 데이터는 변경되지 않는다.
