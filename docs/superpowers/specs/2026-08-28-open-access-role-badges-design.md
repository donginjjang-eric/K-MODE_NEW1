# Open Access and Role Badges Design

## Goal

가입한 운영자·브랜드 파트너·크리에이터가 사람 계정 승인 대기 없이 자기 센터를 즉시 이용하고, 현재 역할을 공통 상단 배지로 명확히 구분한다.

## Policy

- 신규 디자이너와 크리에이터 계정은 즉시 `approved`, 작업공간은 즉시 `active`가 된다.
- 기존 `pending` 사람 계정과 작업공간도 배포 시 자동 활성화한다.
- 사용 정지(`disabled`)와 반려(`rejected`)는 운영 안전장치로 유지한다.
- 상품 공개, AI 결과 공개, 콘텐츠 제출 등 외부 공개물 검수는 유지한다.
- 마스터 이메일은 `운영자`, 그 외 관리자 화면은 `부운영자`, 크리에이터 센터는 `크리에이터`, 패션·뷰티 파트너 센터는 `디자이너` 배지를 표시한다.

## Verification

계정 생성·로그인·작업공간 활성화 계약 테스트, 역할 배지 테스트, 전체 타입 검사와 빌드, 운영 DB 마이그레이션, PC·모바일 페이지 확인을 수행한다.
